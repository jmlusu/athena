## 2. Executive Summary & Core System Philosophy

Athena is an enterprise-grade autonomous recruitment, ATS evaluation, document synthesis, and application dispatching system. It bridges the gap between passive job boards and candidate applications by operating on four inviolable core principles:

1. **Autonomous Intelligence with Strict Human Governance:** Athena crawls the web every 4 hours, computes semantic ATS compatibility scores, and auto-synthesizes bespoke resumes, cover letters, and consultancy proposals. However, **no live application is ever submitted without interactive human digital power-of-attorney authorization and cryptographic sign-off.**
2. **Dehumanized, Pristine Prose:** Content generated by Athena is systematically stripped of telltale artificial intelligence cliches (*e.g.*, "spearhead", "delve", "testament to", "dynamic tapestry") and converted into high-impact, evidence-based executive prose matching elite white-collar standards.
3. **Dual-Column & Single-Column Typography:** Every document is rendered with print-perfect CSS, supporting instant toggling between single-column classic executive format and modern two-column technical advisory format.
4. **End-to-End Traceability:** Every dispatched submission generates a verifiable audit receipt containing a unique receipt ID, SHA-256 confirmation hash, timestamped signatory metadata, and a 7-day automated follow-up reminder schedule.

### 3.1. Sourcing & Multi-Scope Web Aggregation (Req 1, 2, 3, 24)
* **Scope 1 (Lilongwe Local):** Targets on-site employment and consultancy contracts across Lilongwe (Capital Hill ministries, UN Malawi Country Office, USAID contractors, international NGOs like Chemonics/FHI360, commercial banks in City Centre).
* **Scope 2 (Lilongwe Remote):** Targets organizations offering 100% remote delivery while requiring or preferencing Malawi tax residency / Southern Africa timezone alignment (CAT/GMT+2).
* **Scope 3 (International Remote):** Aggregates worldwide opportunities across North America, Europe, Africa, and global multilateral boards matching candidate skills.
* **Platform Integrations:** LinkedIn Talent Ingress, Upwork Enterprise, ReliefWeb, Devex, and corporate job portal parsers.
* **Cadence:** Auto-executed every 4 hours (14,400 seconds countdown) with manual on-demand execution triggers.

### 3.2. Semantic ATS Compatibility Scoring (Req 8, 9, 25)
* **Scoring Range:** 0 to 100 integer score computed via server-side Gemini semantic analysis comparing full job requirements against applicant dossier.
* **Score Tiers & Automated Actions:**
  * **Score $\ge 90$ (Critical Match / Auto-Ready):** Automatically generates tailored pristine resume, cover letter (for jobs), and technical proposal + executive summary (for consultancies). Advances status to `tailored`.
  * **Score $80 - 89$ (Auto-Flagged):** Flags opportunity into the `evaluated` high-priority review queue for human manual tuning.
  * **Score $< 80$ (Standard):** Retained in discovery database with gap analysis indicators.

### 3.3. Pristine Document Studio (Req 4, 5, 6, 7, 20, 21)
* **Tailored Resumes:**
  * Generates bespoke executive summaries, re-prioritized competency matrices, and re-framed past experience bullet points highlighting quantifiable achievements.
  * Instant switcher between **1-Column (Executive Classic)** and **2-Column (Modern Technical)** layouts.
* **Tailored Cover Letters:**
  * Synthesizes role-specific address lines, tailored value propositions, and direct responses to hiring organization priorities.
* **Consultancy Proposals & Executive Summaries (For Consultancies $\ge 90$):**
  * Auto-generates formal 4-section proposals:
    1. Understanding of Context & Terms of Reference (ToR)
    2. Phased Methodology & Work Breakdown Structure (WBS)
    3. Deliverables Matrix & Quality Assurance Schedule
    4. Financial Terms & Milestone Compensation Schedule (USD / MWK)
* **Dehumanizer Engine (Req 5b):**
  * Server-side transformation prompt that replaces AI tropes with authentic human phrasing, concrete nouns, direct verbs, and context-specific Malawian and international terminology.
* **Direct Print & PDF Export:**
  * Clean, borderless `@media print` CSS stylesheet ensuring pixel-perfect A4 / Letter PDF generation.

### 3.4. Online Form Filler & Mandatory Human Sign-Off Gate (Req 10, 11, 12, 13)
* **Form Field Automation:** Auto-maps candidate profile data to standard ATS web forms:
  * Personal Identity (Legal Name, Lilongwe Location, Malawi Phone `+265`, Email, LinkedIn/GitHub URLs).
  * Work Authorization (*e.g.*, "Citizen of Malawi", "Right to Work in SADC / Worldwide").
  * Compensation Expectations (Hourly USD rate, Daily consultancy rate, Monthly MWK salary).
  * Custom Screening Responses tailored to the specific posting.
* **Mandatory Human Sign-Off Gate:**
  * Application dispatch is strictly gated behind an explicit digital authorization step.
  * Requires checking the Power-of-Attorney consent checkbox and typing the authorized legal signer's name.
  * Captures timestamp and generates unique SHA-256 audit signature token prior to submission.

### 3.5. Application Receipts & Follow-Up Ledger (Req 25b)
* **Receipt Generation:** Every submitted application produces an immutable certificate containing:
  * Unique Receipt Identifier (*e.g.*, `ATH-RCPT-882194`).
  * Cryptographic Verification Hash (*e.g.*, `SHA256-BAOBAB-8821-MWK`).
  * Submission Timestamp and Signatory Metadata.
  * Destination Portal & Delivery Status (`SUBMITTED`, `ACKNOWLEDGED`, `INTERVIEW_INVITE`).
* **Automated 7-Day Follow-Up Cadence:**
  * Calculates follow-up date (Submission Date + 7 Days).
  * One-click generation of professional follow-up email drafts referencing the official receipt ID.

### 3.6. n8n Automation Engine & Webhook Node (Req 26)
* Exposes endpoint `POST /api/webhooks/n8n` for external n8n workflow triggers.
* Provides full JSON payload schema and visual 5-node topology in the UI.

## 7. Backend API Specification & AI Interaction Protocol

### 7.1. API Endpoints

#### `POST /api/ai/score-ats`
Calculates the semantic compatibility score between a job description and candidate profile.
* **Request Body:** `{ jobDescription: string, requirements: string[], applicantProfile: ApplicantProfile }`
* **Response:**
  ```json
  {
    "atsScore": 94,
    "matchedSkills": ["Program Architecture", "PostgreSQL"],
    "missingSkills": ["Specific Donor Reporting Tool"],
    "gapAnalysis": "Strong alignment with regional requirements.",
    "dehumanizedPitch": "Brings 10+ years directing complex systems in Lilongwe.",
    "recommendedActions": ["Auto-create tailored resume and proposal"]
  }
  ```

#### `POST /api/ai/tailor-resume`
Generates an ATS-optimized, pristine resume in 1-column or 2-column layout format.
* **Request Body:** `{ job: Opportunity, applicantProfile: ApplicantProfile, columnLayout: "one-column" | "two-column", dehumanize: boolean }`
* **Response:** `{ tailoredResume: TailoredResume }`

#### `POST /api/ai/tailor-document`
Generates a tailored cover letter, executive summary, or consultancy proposal.
* **Request Body:** `{ docType: string, job: Opportunity, applicantProfile: ApplicantProfile, columnLayout: string, dehumanize: boolean }`
* **Response:** `{ document: TailoredDocument }`

#### `POST /api/ai/scrape-live`
Aggregates live or simulated listings across Lilongwe Local, Lilongwe Remote, and International Remote scopes.
* **Request Body:** `{ locationFilter: string, searchType: string, keywords: string, resumeSkills: string[] }`
* **Response:** `{ listings: Opportunity[] }`

#### `POST /api/submit-application`
Handles the authorized submission dispatch and generates a cryptographic receipt.
* **Request Body:** `{ applicationId: string, jobTitle: string, company: string, applicantName: string, authorizationSignature: string, authorizedAt: string }`
* **Response:**
  ```json
  {
    "status": "SUBMITTED",
    "receiptId": "ATH-RCPT-882194",
    "confirmationHash": "SHA256-SIGN-8821-MWK-VALIDATED",
    "submittedAt": "2026-09-26T15:00:00Z",
    "jobTitle": "Lead Systems Consultant",
    "company": "USAID / Digital Impact Malawi",
    "applicantName": "Chifuniro Phiri",
    "authorizedBy": "Chifuniro Phiri (Authorized Signer)",
    "authorizedAt": "2026-09-26T14:59:45Z",
    "nextFollowUpDate": "2026-10-03"
  }
  ```

#### `POST /api/webhooks/n8n`
Receives inbound trigger events from n8n instances and executes pipeline runs.
* **Request Body:** `{ event: string, targetLocations: string[], categories: string[], minimumAtsAutoApply: number, applicantId: string }`
* **Response:** `{ status: "SUCCESS", timestamp: string, processedCount: number, autoCreatedCount: number }`

## 10. Security, Cryptography & Compliance Guarantees

1. **Client-Side Secret Shield:** No `GEMINI_API_KEY` is ever transmitted to or stored in client-side bundles. All LLM calls are routed through server-side endpoints in `server.ts`.
2. **Power-of-Attorney Verification:** Submissions require explicit human interaction. The client cannot dispatch an application without completing the digital signature verification flow.
3. **Audit Immutability:** Generated receipts use SHA-256 confirmation hashes combining the application ID, company name, timestamp, and legal signatory name to prevent fraudulent submission claims.
